# Project guidance

- This repository is the v0 source for ayush.me. Edit `data.js` for the site's copy, links, command labels, and portfolio entries. The `portfolio/` directory is a separate reference and is not read by the frontend or build.
- Preserve the two-pane concept: Ayush's introduction and GitHub activity on the left, interactive terminal on the right.
- Keep the light palette blue and white, and the dark page background pure black with blue accents. Use the bundled Geist Mono font for the terminal.
- Terminal commands show a short thinking state and reveal responses progressively. Honor reduced-motion preferences by displaying responses immediately.
- Keep the terminal free of a title bar and outer frame. Center its command bar until the first command, then animate it to the bottom of the right pane.
- The command content and achievement entries are reference placeholders for v0. Do not silently rewrite them as Ayush's verified biography. Ayush's supplied intro and social links take priority wherever they conflict.
- Keep the site responsive, keyboard-accessible, and dependency-free unless a requirement justifies a dependency.
- Do not add a README file.
